# Lobby do Torcedor FURIA

Protótipo criado para o Desafio Técnico da vaga de **Assistente de Engenharia de Software** da FURIA Tech.

## Sobre o Projeto

O "Lobby do Torcedor FURIA" é um aplicativo que centraliza a experiência do fã em um só lugar. É como uma carteira digital para torcedores apaixonados, combinando funcionalidades informativas, interativas e gamificadas. 

Meu objetivo foi criar um espaço que conecta os fãs com o ecossistema da FURIA: jogos, conteúdos, influenciadores, loja, redes sociais e muito mais — tudo com personalização e recompensas baseadas no engajamento.

## Funcionalidades Propostas

- **Perfil do Torcedor** com integração às redes sociais
- **Gamificação de Engajamento** com pontuação baseada em:
  - Uso de #FURIA nas redes
  - Acesso ao app
  - Visualizações de conteúdos
  - Interações com influenciadores parceiros
- **Ranking de Fãs** e sistema de "UP" de perfil
- **Chatbot FURIA** para tirar dúvidas ou interagir (versão app ou integração com WhatsApp)
- **Notícias, Escalações e Jogos**
- **Loja oficial com produtos integrados**
- **Área exclusiva por modalidade (CS, LoL, VALORANT, etc.)**
- **Links diretos para streamers e influenciadores oficiais**

## Tecnologias e Ferramentas Utilizadas

- Figma (prototipagem de telas)
- ChatGPT (ideação e estruturação)
- Canva (mockup visual)
- GitHub (documentação e organização)
- Pesquisa de mercado via Google Play Store
- Pesquisa de informações via Furia.gg e escharts.com
